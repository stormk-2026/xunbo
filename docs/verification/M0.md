## 闭环证据

`exploreEducationTabFromContentCard` 从精品内容卡片“沙漠往事”出发，自动执行：

```text
UP → RIGHT → RIGHT → RIGHT → OK
```

这是测试实际观察并断言的结果，不是用户给 Agent 的操作序列。每一步由新 ScreenState 决定并校验，最终 activeTab=教育，TaskStatus=SUCCEEDED，总计 5 键，未发送 POWER。测试同时比对 Fake 发射记录与每键 trace。

安全回归覆盖：最多一次重试及计步、末步预算、观察／决策挂起超时、WAIT 时限、停止后迟到决策不能发键、新任务可重新运行、并行任务拒绝、队列串行和清空、低置信度与危险文字阻止 OK、焦点不等于选中／激活、错误集数拒绝、同名元素不误判循环、跳格停止、错误 arrived 不得成功、四类数据 JSON 往返。

耗时说明：FakeClock 仅推进逻辑时间，不代表相机、红外、网络或 Jev 的真实速度。本轮无真实延迟、动作准确率或 token 消耗测量。
